조달타운 v0.3.2 | 10년 도시 성장 시즌

ZIP 전체를 압축 해제한 뒤 index.html을 Chrome 또는 Edge로 여세요.
폴더 안의 js, css, assets를 함께 유지하세요. 인터넷이나 별도 설치는 필요 없습니다.

새 시즌: 밝게 표시된 학교를 선택해 튜토리얼을 시작합니다.
좌클릭 선택 / 우클릭 드래그 이동 / 휠 확대·축소. Tab·Enter·Space와 Esc도 지원합니다.
안내 카드에서 저장·설정·도움말·건너뛰기를 사용할 수 있습니다.
건너뛰기는 학교 의뢰를 자동 완료하지 않습니다.

저장: JSON 파일 내보내기와 불러오기를 사용하세요. 자동저장 키는 jodaltown-save-v3입니다.
이전 v1/v2 기록은 읽기 전용으로 열리며 기존 키를 덮어쓰지 않습니다.
설정의 튜토리얼 다시 보기는 실제 도시를 보존하는 별도 연습 모드입니다.

연간 기본 예산 4,000만 + 성과 보조금 최대 1,000만. 계약 시 예약, 인수 시 집행.
미사용 예산은 만료합니다. 다년도 계약 약정은 원래 재원을 유지하며 새해 예산에서 다시 차감하지 않습니다.
연말 결산에서 인구 변화의 사유를 확인한 뒤 다음 해를 시작하세요. 총 10년입니다.
