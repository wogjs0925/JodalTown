# 조달타운 v0.3.2

10년 동안 공공조달 사업을 진행하며 인구 500명의 도시를 성장시키는 오프라인 교육 게임입니다. 사용자 제공 GDD v2, v0.2 확장 설계, v0.3 통합 명세를 바탕으로 기존 TypeScript 게임을 확장했습니다.

## 실행

PC ZIP을 **모두 압축 해제**하고 `index.html`을 Chrome 또는 Edge로 여세요. JS/CSS/assets 폴더를 함께 유지해야 합니다. 인터넷·서버·실행 파일 설치가 필요하지 않습니다. 파일을 연 경로가 바뀌면 자동저장이 달라질 수 있으므로 이동 전 JSON 저장을 권장합니다.

새 시즌에서는 밝게 표시된 학교를 선택합니다. 8단계 안내는 요구조건 → 적격 판별 → 계약 예약 → 규격 검사 → 수량·손상 검수 → 보완·재확인 → 인수·시설 성장 → 첫해 결산을 따라갑니다. 학교 PC는 30대, RAM 16GB·SSD 512GB·보증 3년 이상이며 B 2,700만이 첫 계약의 적격 최저가입니다.

## 조작과 안내

- 좌클릭: 시설/버튼 선택. 우클릭 드래그: 지도 이동. 휠: 확대/축소.
- Tab으로 현재 단계의 조작과 안내 메뉴를 순환하고 Enter/Space로 실행합니다. Esc는 안내 일시정지 또는 열린 보조 창 닫기입니다.
- 설정에서 음량·무음·저사양·야간·모션 축소·지도 이동 화살표를 조절합니다.
- ‘건너뛰기’는 안내만 닫습니다. 첫 학교 구매를 직접 끝내야 다음 해로 갑니다.
- ‘튜토리얼 다시 보기’는 별도 연습입니다. 실제 시즌 자동저장을 유지하며 ‘연습 종료’로 복귀합니다. ‘새 기능 안내 다시 보기’는 해당 시즌의 안내 확인 표시만 초기화합니다.
- 전체 개봉은 보조 기능입니다. 한 물품 카드를 직접 확인하거나 문제를 표시하거나 ‘물품 1개 비교’로 직접 판단 기록을 남깁니다. 계약과 같은 물품은 문제로 표시하지 않습니다.

## 연간 장부

기본 예산은 연간 4,000만이며 완료 사업당 100만, 인구 500명 초과 100명당 100만의 성과 보조금을 최대 1,000만까지 더합니다. 실제 법정 산식이 아닌 게임 규칙입니다.

계약하면 예산을 예약하고 검사·검수 후 정상 인수할 때 집행합니다. 보완 요청 자체에는 벌점이나 추가 집행이 없습니다. 동시에 두 계약을 진행할 수 있습니다.

미사용 잔액은 결산 시 만료하며 다음 해에 자동 이월하지 않습니다. 다음 해 납품 계약은 **최초 연도 재원에 약정으로 보존**됩니다. 새해 예산에서 중복 차감하지 않습니다. 공급 차질로 합의해제가 승인된 계약만 취소할 수 있습니다. 닫힌 연도의 예약 반환은 그 연도에서 만료되어 올해 현금으로 전환되지 않습니다.

연말 결산과 다음 해 시작은 별도 버튼입니다. 사건이 있으면 먼저 확인하세요. 연간 장부와 과거 결산은 ‘도시기록’에서 열람합니다. YEAR 10에 마지막 결산과 도시 성적표를 표시합니다.

## 인구와 시설

서비스는 기본 45점에 완료 사업 효과를 더하고 유지비 영향을 반영합니다. 기본 정착 1%와 서비스 효과를 더한 성장률은 ±6%로 제한합니다. 미인수·미해결 품질 건당 4명, YEAR 3부터 미충족 소방·의료 서비스당 3명을 차감합니다. 최종 변화 ±8%, 최소 100명 보호를 적용하고 모든 변동 사유를 결산에 표시합니다. 정당한 보완으로 품질 문제를 해결하면 해당 차감이 해소됩니다.

## 기업 뉴스

YEAR 3부터 연간 1–2건의 허구 기사를 제공합니다. 회사·제목·연도로 검색할 수 있고 업체 카드의 이력과 근거를 열람할 수 있습니다. 의혹은 자동 배제나 신뢰도 감점 사유가 아닙니다. 확인된 실적·하자도 공개 기준 밖의 임의 가점·감점이 되지 않습니다. 가상 공식 제한은 유효 연도와 지정 경로만 적용합니다. 현재 시나리오의 제한은 YEAR 5 경쟁입찰이며 YEAR 6에 만료합니다. 실제 업체·실제 기사·법적 제재 목록이 아닙니다.

## 저장

저장 버전 3, 자동저장 키 `jodaltown-save-v3`입니다. 튜토리얼 단계, 계약 전 선택, 검사·검수 입력, 연도별 약정·인수·기업 이력·뉴스를 JSON으로 내보냅니다. 안내 중에는 안내 카드의 저장 또는 설정의 불러오기를 사용하세요. 브라우저 저장소가 막히면 파일 저장을 사용합니다.

v0.1/v0.2 저장은 ‘지난 시즌 기록’으로 읽기 전용 표시합니다. 원본 다운로드가 가능하며 기존 키 `jodaltown-save-v2`를 수정하지 않습니다. 이전 활성 계약을 연도로 임의 환산하지 않습니다. 새 연간 시즌을 시작하려면 별도로 새 게임을 선택합니다.

## 개발과 재빌드

Node.js 20 이상과 npm 사용. `npm ci`로 개발 의존성을 설치하는 과정에만 네트워크가 필요합니다. 완성된 PC 게임은 오프라인입니다.

```text
npm ci
npm run typecheck
npm test
npm run build:pc
npm run check:offline
npm run test:browser
npm run test:tutorial
npm run test:fallback
npm run package:pc
```

브라우저 테스트는 설치된 Chrome/Edge를 사용합니다. 구 버전 브라우저 테스트는 v0.2.1 백업 빌드를 대상으로 사용하세요. 신규 기본 테스트 명령은 v0.3 전용입니다.

| 파일 | 역할 |
|---|---|
| src/main.ts | 화면·입력·저장 연결, 연간 보고서, 뉴스, 연습 모드 |
| src/ui/spotlight.ts | 네 면 마스크, 목표 추적, 입력/키보드 제한 |
| src/core/tutorial.ts | 안내 단계와 실제 상태 검증 |
| src/core/annualState.ts | 연간 예산·약정·결산·인구·사업 상태 |
| src/core/annualFlow.ts | 구매/검수 화면 진행 |
| src/core/annualRules.ts | 참가 제한과 기존 선정 기준 결합 |
| src/content/annual.ts | 연간 일정·시설 개방·공통 공급사·뉴스·게임 산식 설정 |
| src/save/annualPortable.ts | 버전 3 저장 검증과 이전 기록 보존 |
| src/scene/town.ts | 시설 외형·우클릭 팬·클릭 구분 |
| src/style/game.css | 반응형 화면·HUD·안내 카드 |

검증 근거와 미검증 범위는 TEST_REPORT.md, 변경 내역은 CHANGELOG.md를 참조하세요. 정책 참고자료 링크는 도움말에서 사용자가 누를 때만 열리며 실행 중 외부 자원을 요청하지 않습니다.

## v0.3.1 변경

타이틀 저장 보호·연습 복귀·누적 결산·검수 안내를 수정했습니다. 여섯 시설의 LV.0/1/2 외형 18개를 추가했고 실제 레벨에 연결했습니다. 건물 변화는 서비스 성장의 시각적 표현이며 별도 건설비를 추가하지 않습니다. 현재 사업 구성에서 도서관·공원은 LV.1까지 도달합니다. 자세한 문제 재현과 수정 사항은 AUDIT_REPORT.md, 외형 비교는 assets/building-levels.png를 참조하세요.


## v0.3.2 안내 버튼 수정

필수 조건 읽기의 확인 버튼을 항상 보이는 안내 카드 안으로 옮겼습니다. 조건표를 스크롤해 숨은 버튼을 찾을 필요가 없습니다. v0.3.0·v0.3.1 저장을 그대로 이어갈 수 있습니다. 이미 열어둔 화면은 새로고침 후 이어하기로 적용하세요.
